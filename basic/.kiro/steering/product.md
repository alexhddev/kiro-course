# Product Overview

**EventsPro** is an event planning company landing page showcasing their services and contact information.

## Core Sections

- **Hero**: Company name (EventsPro) with tagline "Creating Memorable Experiences"
- **Services**: Display of event planning offerings
- **Contact**: Contact information with email and phone links
- **Footer**: Copyright and additional information

## Design Philosophy

- Mobile-first responsive design
- Clean, accessible interface using semantic HTML
- Support for light and dark color schemes
- Focus on user experience and readability
